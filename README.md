# 🛒 PedevApp — Sistema de PDV para mercearias

Sistema web de **frente de caixa (PDV) e gestão** para mercearias e pequenos mercados: do caixa à validade dos produtos, numa tela só.

> 🔒 O código-fonte é privado. Este repositório mostra o sistema em funcionamento: **telas reais**, com dados de exemplo.

## 🎬 Demonstração
**[▶️ Assistir ao vídeo (55s)](PedevApp-LinkedIn-telas-reais.mp4)**

## Funcionalidades
- **Caixa rápido:** leitor de código de barras, Pix, cartão, dinheiro e fiado, com baixa automática no estoque
- **Validade por lote:** vários lotes por produto, saída do que vence antes, avisos a partir de 1 mês antes e baixa do vencido com um clique
- **Central de avisos:** validade, contas a pagar e lembretes, com sino de notificações e "marcar como lida"
- **Ajudante com IA:** o usuário pede por texto ou áudio (ex.: "lança a conta de gás de 135 reais") e o Ajudante prepara o cadastro, é só confirmar
- **Clientes e fiado:** limite de crédito por cliente e histórico de compras
- **E mais:** importação de nota fiscal (XML), relatórios, atalhos de teclado (F2–F10), perfis de dono e funcionários e várias lojas

## Tecnologias
TypeScript · Aplicação web · IA generativa

### PedevApp — Point-of-sale system for small grocery stores

Web-based **POS and store management** system for small grocery stores, from checkout to product expiration dates, all in one screen.

> 🔒 Source code is private. This repository showcases the system running: **real screens** with sample data.

**[▶️ Watch the demo video (55s)](PedevApp-LinkedIn-telas-reais.mp4)**

- **Fast checkout:** barcode scanner, Pix, card, cash and store credit, with automatic stock updates
- **Batch expiration tracking:** first-expired-first-out, alerts one month ahead
- **Notification center:** expiring products, bills to pay and reminders
- **AI assistant:** create records by text or voice and just confirm
- **Customers & store credit**, XML invoice import, reports, keyboard shortcuts, owner/staff roles and multi-store support

Built by **Bruna Aganett** with AI assistance (Claude Code): requirements, business rules, testing and validation.
